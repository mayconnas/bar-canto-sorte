# Screenshots

Coloque aqui os prints do app rodando no tablet.

Sugestao de arquivos (os nomes referenciados no README principal):

- `mesas.png`     — mapa de mesas, com algumas ocupadas
- `pedido.png`    — painel de lancamento com uma mesa selecionada
- `checkout.png`  — tela de fechamento de conta
- `relatorio.png` — relatorio de vendas do dia

## Como capturar no Android

Com o aparelho conectado via USB e depuracao USB ativada:

```bash
adb exec-out screencap -p > mesas.png
```

Ou use o print nativo do aparelho (Power + Volume-) e transfira os arquivos.

Depois de salvar as imagens aqui, edite o README.md da raiz: troque a secao
"Screenshots" pela tabela que esta comentada logo acima dela.
